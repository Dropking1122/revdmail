Tentang REVDMAIL

Apa itu REVDMAIL?

REVDMAIL adalah platform disposable temporary email service yang dirancang untuk melindungi kotak masuk utamamu dari spam, newsletter tak diinginkan, dan kebocoran data saat mendaftar akun di situs web asing.

Fitur Utama

  • Instant Generation: Buat alamat email acak dalam 1-klik tanpa signup.
  • Auto OTP Extraction: Deteksi instan kode verifikasi 4–8 digit untuk kemudahan 1-tap copy.
  • Multi-Domain Catch-all: Akses ke berbagai domain pilihan.
  • Sandbox Security: Isolasi rendering HTML email mencegah eksekusi skrip berbahaya.

Dokumentasi REST API

Public REST API (Tanpa Autentikasi)

Base URL: https://mail.revd.me/api. Rate limit: 60 request / menit per IP.

POST /api/create
Buat Email Acak / Kustom

Membuat alamat email sementara baru. Bisa menentukan username atau domain kustom jika diinginkan.

Request Body (JSON - Opsional):
{
  "username": "tester123", // Opsional
  "domain": "revd.me"       // Opsional
}
Contoh cURL:
curl -X POST https://mail.revd.me/api/create
GET /api/messages?email={email}
Daftar Kotak Masuk (Inbox)

Mengambil seluruh pesan masuk untuk alamat email target.

Contoh cURL:
curl -s "https://mail.revd.me/api/messages?email=user@revd.me"
Format Respon JSON:
{
  "messages": [
    {
      "id": 2083,
      "subject": "Kode Verifikasi Akun Anda",

GET /api/message/:id?email={email}

Contoh Otomasi Node.js (Polling OTP) 

const BASE = 'https://mail.revd.me/api';

async function main() {
    // 1. Buat email baru
    const { email } = await fetch(`${BASE}/create`, { method: 'POST' }).then(r => r.json());
    console.log('Email Aktif:', email);

    // 2. Polling inbox mencari kode OTP
    const timer = setInterval(async () => {
        const { messages } = await fetch(`${BASE}/messages?email=${email}`).then(r => r.json());
        if (messages && messages.length > 0) {
            console.log('Pesan Masuk:', messages[0].subject);
            // Ekstraksi 4-8 digit OTP
            const match = messages[0].intro.match(/\b\d{4,8}\b/);
            if (match) {
                console.log('OTP DITEMUKAN:', match[0]);
                clearInterval(timer);
            }
        }
    }, 4000);
}
main();
